Aquí va `clasificador-senas.json`, el modelo que genera `python ml/entrenar.py`.
Si el archivo no existe (o no conoce una seña), la app igual funciona: esa seña solo verifica
que se vieron las manos, sin evaluar si está bien hecha.

`zorro-cara.webp` es la cara del zorrito 3D (avatar de AI Studio), horneada desde la ilustración
oficial con `python ml/avatar/proyectar.py` (ver `ml/avatar/README.md`). Si falta, el zorrito usa
una cara modelada.
